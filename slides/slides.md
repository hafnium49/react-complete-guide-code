## Slide 1: What is NextJS?

---

## Slide 2: The React Framework for Production

> A **fullstack** framework for ReactJS

---

## Slide 3: Why NextJS?

> NextJS **solves common problems** and makes building React apps **easier**!

---

## Slide 4: The React Framework for Production (Details)

| You Still Use React | Built-in Features | Production-Ready |
|--------------------|-------------------|------------------|
| You still write React code, you still build React components and use React features (props, state, context, ...) | Lots of built-in features (e.g. routing) that help you solve common problems & clear guidance on how to use those features | There are certain problems which you will need to solve for almost all production-ready React apps: NextJS solves those for you |
| NextJS just enhances your React apps and adds more features | | |

---

## Slide 5: NextJS - Key Features & Benefits

| File-based Routing | Server-side Rendering | Fullstack Capabilities |
|-------------------|----------------------|------------------------|
| Define pages and routes with files and folders instead of code | Automatic page pre-rendering: Great for SEO and initial load | Easily add backend (server-side) code to your Next / React apps |
| Less code, less work, highly understandable | Blending client-side and server-side: Fetch data on the server and render finished pages | Storing data, getting data, authentication etc. can be added to your React projects |
