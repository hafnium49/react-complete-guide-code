## Slide 9: Using "Just JavaScript" Isn't A (Great) Option

- It quickly becomes **cumbersome**
- It quickly becomes **error-prone**
- It quickly becomes **hard to maintain** or edit
- **React** offers a way **simpler "mental model"**

## Slide 10: React = Declarative UI Programming

**With React, you define the target UI state(s) — not the steps to get there**

Instead, React will figure out & perform the necessary steps

### Different Paradigms

| Declarative | Imperative |
|-------------|------------|
| Define the goal, not the steps | Define the steps, not the goal |

## Slide 18: Creating React Projects

| Local Setup | Browser-based Setup |
|-------------|---------------------|
| Create React projects **locally** on your system | Create **remote** React projects via CodeSandbox (or similar) |
| **Requires installation** of tools & creation of files on your system | **No software installed**, no files created on your local system |
| Use a locally installed code editor (e.g., VS Code) with **any settings and extensions** of your choice | Use a (mostly) **pre-configured** code editor inside of your browser |
